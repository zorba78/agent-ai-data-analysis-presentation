# 스타터킷

연구 프로젝트에서 Claude Code를 처음 쓸 때 필요한 최소 파일 묶음. 발표 "Positron 기반 에이전트 AI 활용 연구 워크플로우"의 배포 자료.

발표 3막에서 다룬 대사증후군 연구(공군 조종사 대 국민건강영양조사 남성)의 프로젝트 폴더에서 실제로 쓴 설정을 바탕으로 만들었고, 파일마다 그 연구의 내용을 "사례"로 적어 두었음. 연구 자료와 결과 파일은 들어 있지 않음.

| 파일 | 내용 | 넣는 곳 |
|---|---|---|
| `CLAUDE.md` | 프로젝트 지침 템플릿. `<여기에: …>`를 채워 사용. 빈칸마다 사례의 실제 내용 | 프로젝트 폴더 맨 위 |
| `folder-structure.md` | 사례의 폴더 구조, 실행 폴더와 진행 기록 양식, 폴더를 만드는 R 코드 | 읽고 R 코드 실행 |
| `.claude/settings.json` | 사례의 권한 설정에 승인 항목을 더한 것 | 프로젝트 폴더의 `.claude/` |
| `verification-checklist.md` | 결과 확인 체크리스트. 항목마다 사례에서 실제로 확인한 내용 | 인쇄하거나 프로젝트 폴더에 보관 |
| `install-guide.md` | Positron, Claude Code, MCP 설치 순서 | 읽고 따라 하기 |

## 쓰는 순서

1. `install-guide.md`대로 설치
2. `folder-structure.md`의 R 코드로 폴더 생성
3. `CLAUDE.md`와 `.claude/settings.json`을 프로젝트 폴더에 복사하고 빈칸 채우기
4. 프로젝트 폴더에서 `claude` 실행
5. 결과가 나올 때마다 `verification-checklist.md`로 확인

## 권한 설정 읽는 법

- `allow`: 묻지 않고 실행. R과 Python 스크립트 실행(사례 프로젝트와 같음)
- `ask`: 매번 승인. 삭제, 원격 저장소 올리기, 외부 전송(스타터킷에서 더한 항목)
- `deny`: 금지. 원자료 편집(사례 프로젝트와 같음), 연구자 코드 폴더 편집
- 목록에 없는 명령은 실행 전에 승인을 물음
- 한계: `deny`의 편집 금지는 편집 도구만 막음. R 코드가 파일을 쓰는 것은 막지 못하므로 원자료 폴더는 운영체제에서도 읽기 전용으로 설정

## 주의

- 압축을 풀면 `.claude` 폴더가 숨김 처리되어 안 보일 수 있음. 탐색기에서 숨김 항목 표시
- 도구 설정 방법은 2026년 11월 기준. 바뀔 수 있으므로 공식 문서와 대조
