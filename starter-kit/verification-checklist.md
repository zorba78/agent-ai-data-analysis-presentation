# 결과 확인 체크리스트

에이전트가 낸 결과를 원고에 넣기 전에 연구자가 확인하는 항목. 판별 기준은 두 가지: 가설이 연구자의 것인가, 결과를 연구자가 설명할 수 있는가.

"사례" 열은 발표에서 다룬 대사증후군 연구(공군 조종사 대 국민건강영양조사 남성)에서 실제로 확인한 내용.

## 가설 검토

| 확인 | 항목 | 사례 |
|---|---|---|
| ☐ | 가설은 내가 세웠고, 결과를 본 뒤에 고쳐 쓰지 않았음 | 가설 H1–H3을 분석계획서에 적은 뒤 분석 시작 |
| ☐ | 분석 전에 분석계획서를 확정했음 | 정의, 공변량, 모형, 다중 비교 방침을 미리 확정. 바꿀 때마다 판 번호와 날짜 기록 |
| ☐ | 에이전트에게 약점과 반대 근거를 먼저 요구했음 | 에이전트가 정의의 순환성과 희소 셀 문제를 먼저 지적 |
| ☐ | 계획보다 복잡해진 분석을 줄였음 | 에이전트가 붙인 추가 모형과 민감도 분석을 삭제하고 표를 단순화하도록 지시 |

## 정량 분석

| 확인 | 항목 | 사례 |
|---|---|---|
| ☐ | 표본 수: 제외 단계별 대상자 수가 흐름도와 일치 | 조종사 남성 2,739명, 국민건강영양조사 1,174명 → 완전사례 3,823명(2,738 + 1,085). 단계별 수를 flow.csv로 저장 |
| ☐ | 변수 코딩: 숫자 코드를 범주로 바꾼 결과를 교차표로 확인 | 리코딩 검증 14개 변수 모두 일치 |
| ☐ | 변수 정의: 두 자료에 같은 정의를 적용 | 대사증후군을 원변수에서 다시 계산. 원래 들어 있던 변수와 52명(1.9%) 불일치, 원인까지 확인 |
| ☐ | 결측: 변수별 결측 수와 처리 방법을 확정 | 완전사례 분석으로 확정. 제외 1명, 89명을 흐름도에 표시 |
| ☐ | 가중치와 표본 설계: 적용 여부와 이유를 기록 | 조종사 자료에 가중치를 줄 수 없어 가중치 없이 비교하기로 확정하고 한계로 기술 |
| ☐ | 모형: 모형 식, 보정 변수, 기준 범주를 코드에서 확인 | 기준 집단을 국민건강영양조사로 지정했는지 확인(OR = 조종사 대 일반 인구) |
| ☐ | 숫자 재계산: 원고의 숫자를 따로 다시 계산해 대조 | 표의 OR을 다른 에이전트가 독립적으로 다시 계산해 모두 일치. 대사증후군 11.2% 대 39.6%, 보정 OR 0.27(0.23–0.33) |
| ☐ | 희소 셀: 사건 5 미만 셀을 감추었는지 확인 | 감춘 셀 없음(최소 사건 6). 기준 셀이 작은 분석은 신뢰구간이 넓다고 기술 |
| ☐ | 자료가 바뀌지 않았는지 확인 | 표 형식만 고친 뒤 자료 파일의 md5가 같은지 확인 |
| ☐ | 계획에 없는 분석은 "탐색"으로 표시 | 다중 비교 보정을 하지 않고, 검정 수와 탐색적 성격을 각주에 기재 |
| ☐ | 개인 단위 자료가 산출물과 로그에 없음 | 모형 객체는 개인 단위 자료를 포함하므로 저장하지 않음 |

## 문헌 수집

| 확인 | 항목 | 사례 |
|---|---|---|
| ☐ | 모든 문헌의 PMID 또는 DOI가 실제로 조회됨 | 수집한 232편을 PMID로 대조. 핵심 6편은 PubMed에서 다시 확인 |
| ☐ | 저자, 연도, 권과 쪽이 원문과 일치 | 선행 논문의 권, 호, 쪽을 문헌 검색 결과로 바로잡음 |
| ☐ | 인용한 내용이 원문에 있음(본문에서 확인) | 문헌을 읽고 내 분석계획서의 혈압 측정 방식 기술이 틀렸음을 발견해 수정 |
| ☐ | 철회된 논문이 아님 | |
| ☐ | 내 결과와 다른 방향의 문헌도 고찰에 반영 | |
