    • 언어: Rmd는 R 중심. qmd는 R(knitr), Python(Jupyter), Julia, Observable JS 엔진을 문서마다 고름
    • 확장: Rmd에서 bookdown, xaringan, blogdown, distill로 나뉘던 기능이 Quarto 하나에 내장(책, 발표, 웹사이트, 상호참조, 탭, 콜아웃)
    • 문법: 청크 옵션을 #| echo: false 형식으로 청크 안에 YAML로 씀. 출력 형식별 옵션도 YAML 통일
    • 계속 지원: R Markdown도 유지보수는 계속됨. 새 기능은 Quarto에만 추가
    • 이 사례: 2026-03 분석 보고서부터 qmd. 발표자료도 qmd

  • 복사, 붙여넣기 단계가 없어짐
  • 결과에 DOI, 출처가 붙어 검증 가능

  • 쓰는 도구만 연결. 많으면 선택이 흐려짐
  • 권한 allow에 도구 이름 단위로
  • 연결 상태 확인: claude mcp list
  • 시간: 1.5분
  • 메시지 한 줄: 에이전트의 손을 늘리는 규격. 데이터는 안 나가고 질의만 나감
  • 개념: Anthropic이 공개한 규격, 다른 에이전트도 지원. 서버는 로컬 프로세스 또는 원격
