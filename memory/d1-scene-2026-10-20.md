# D1 시연 장면 변경 2026-10-20

- 매개분석(BMI → URATE/GLUC → MeTS)은 출판 논문에 없음. 제외 이유(사용자): 초기에 생각했던 분석 방향과 맞지 않는다고 판단
- 그래서 매개분석 장면(07-mediation-env-error)은 시연 소재로 쓰지 않음
- D1은 07-factor-prevalence-zero로 교체: factor 열을 숫자로 가정 → 유병률 전부 0% → class 확인 → `.x == "Yes"`로 수정. 최종 유병률이 출판 논문 표와 일치(복부비만 13.0% vs 45.3%, 혈압 47.7% vs 38.8%)
- 영상 방식: 실제 화면 녹화 대신 로그 재현 GIF. `scripts/make_d1_gif.py` → `demo/clips/D1-error-fix-sample.gif`(20초 예시). 화면에 "실제 로그 재현" 표시
